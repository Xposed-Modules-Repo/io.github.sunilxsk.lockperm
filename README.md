# LockPerm

LockPerm 是一个基于 **libxposed** 的 Xposed 模块，按应用提供「伪装」与「防护」能力。它只在目标应用进程内工作，不常驻后台；每个应用的配置互相独立，互不影响。

## 核心能力

### 伪装

**设备信息**：Build 字段、Android ID、GSF ID、广告 ID、App Set ID、DRM ID、OAID、Firebase ID

**硬件与内核**：内核版本、架构、CPU 信息、温度、电量

**网络与 SIM**：WiFi / 蓝牙 MAC、SSID、BSSID、IMEI / MEID / ICCID / IMSI、运营商、手机号

**系统环境**：时区、语言、伪装开发者选项已关闭

**其他伪装**：Root 伪装、VPN / 代理隐藏、WiFi 连接状态伪装、WebView JS 注入

**权限伪装**：让应用以为已授权，部分权限可返回伪造数据（通讯录、短信、通话记录、存储、位置、日历）

### 防护

无障碍权限禁用、设备管理员权限防护、悬浮窗创建拦截、壁纸修改拦截、音量控制拦截 / 固定音量、音频输出拦截、剪贴板拦截、闪光灯 / 振动拦截、WiFi / 蓝牙 / 亮度控制拦截、传感器拦截、跳转拦截、摄像头 / 麦克风实时拦截、安装拦截、打印 / 投屏拦截、发送通知拦截、屏幕捕获拦截（用图片 / 视频替换画面）、文件创建拦截、隐藏应用列表

**使用**

1. 在 LSPosed 管理器中启用本模块。
2. 在「应用」页为目标应用添加作用域。
3. 点该应用的「配置」进入专属配置页，在「防护功能」与「伪装」两个页签里勾选需要的功能。
4. 修改配置后**强制停止目标应用再打开**即可生效。
